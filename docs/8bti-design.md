# 8BTI · 骗子人才测评（已否决，仅作记录）

状态：2026-10-14 讨论后决定**不实施**。正式人格结果维持现状：`src/story.js` 里 `PROFILE_TYPES` 的 8 个外号 + 3 个隐藏款。接手开发不要按本文实现，本文仅留作设计讨论记录。

## 定位

测出来的结果是一个**爆梗外号**——「地主家的傻儿子」「小馋猫」这种俗语系噱头，用户一看就想截图发群。8BTI 保留为系统名（8.8 Bait Type Indicator），但四字母不占 C 位，只作为结果卡角落的「骗子人才库档案编号」小字彩蛋，给懂 MBTI 的人一个会心一笑的暗号。

品牌安全边界（不变）：

- 外号全部标注「骗子视角 · 骗子给你起的」，页面固定保留「只代表本局选择，不代表你天生好骗」。
- 不暗示心理测评。包装用「诈骗集团人才库 · 内部资料」假章制造氛围。
- 「傻儿子」「呆瓜」这类词只能出现在骗子起的外号里，且每张卡都配一句防御口诀把人扶起来。

## 结果卡结构（从上到下）

1. **本命外号**（大字，主角）：俗语系爆梗，全池 18 个。
2. **骗子遇见率**（幽默百分比 + 一句注）：如「82% · 骗子满意度调查中心友情提供」。纯玩笑数字，标注由「骗子满意度调查中心」提供，避免被当成真实统计。
3. **骗子记号 ×3**（三连小标签）：从 12 个标签池按信号阈值抽 3 个，组合出「小馋猫 + 手快过脑 + 心软的神」这种连招感。
4. **骗子评语**（一句）+ **防御口诀**（一句）。
5. **档案编号**（小字）：8BTI 四字母，如「档案编号 STCD」。

三层噱头叠加（外号 + 遇见率 + 三连标签）保证两个人同结局也不撞卡，这是不用写 16×16 文案就能拿到的组合丰富度。

手快过脑（pressure）· 心软的神（familiar）· 8 块 8 心动体质（bait）· 倒计时过敏（rush）· 群聊水体贡献者（crowd）· 填坑爱好者（sunk）· 远程操作优等生（obedience）· 截图取证狂魔（verify）· 验证码守门员（privacy）· 付款栏常驻嘉宾（invested>0）· 官方渠道钉子户（verify 高）· 传播链绝缘体（referral 低且 verify 高）

规则：按信号强度排序取前 3；不足 3 个时从「传播链绝缘体」等安全标签补齐，保证每个人都有三连。

## 呈现与传播

1. 揭晓动效：先盖「骗子评语」红章，再甩出外号大字（Motion 现有能力）；危险侧配骗子鼓掌音效，安全侧撒彩带。
2. 分享行（最短传播单元）：「我在骗子人才库的代号是『地主家的傻儿子』，骗子遇见率 61%」。
3. 重玩钩子：结果页列出「骗子人才库还有 N 个外号你没解锁」，按信号最近邻提示（「差一点点就是急刹车专业户」），驱动换路径重玩，正好服务走完 S/B/C 三条路径的教学目标。
4. 相性一句话保留：按主导信号给「和室友组队」文案（每信号 1 条，共 8 条）。
