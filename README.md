# 《8.8元到账之后》

校园反诈主题互动 H5，以可戳破的骗局气泡序章、AI 海报、连续动作视频和分支短剧融合呈现。男女主角各有 8 段独立镜头，包含取放与滑动手机、抬手停顿、转身求证、后仰警觉和停止手势等手部、手臂与上半身动作。用户先识别八类当代校园高发骗局，再选择男女角色进入同一条“兼职刷单返利”剧情，通过选择抵达 S / B / C 三种结局，随后完成骗局复盘、迁移测试、985 高校官方案例学习，并生成可下载的反诈识别力卡片。

## 本地运行

```powershell
npm install
npm run dev
```

生产构建：

```powershell
npm run test
npm run build
npm run preview
```

生成可直接双击打开、无需本地服务器的离线单文件：

```powershell
npm run build:standalone
```

输出文件为 `dist/8.8元到账之后-离线单文件.html`。该文件内嵌人物图、短剧镜头、原创配乐、样式与脚本，适合作为投稿附件和断网演示备份。`release/` 同时提供约 30 MB 的网站部署包与离线演示包，避免在同一个压缩包里重复存放图像。

手机与电脑处于同一局域网时，执行 `npm run dev:lan`，再用手机访问终端显示的 Network 地址。本机当前示例为 `http://183.172.61.28:4185/`；IP 地址会随网络变化，以终端当次显示为准。校园 Wi-Fi 可能启用终端隔离，如果同一校园 Wi-Fi 仍打不开，可让电脑开启移动热点、手机连接该热点后再使用热点网段地址访问。

## 体验流程

1. 逐个戳破刷单返利、客服退款、门票私下交易、AI 换脸换声、游戏账号交易、虚假实习内推、屏幕共享、助学金与校园贷八类骗局气泡，读出每类骗局最关键的危险信号。
2. 进入主题海报，选择小清（女）或小华（男），以八段连续动作短剧视频进入虚拟网络世界。
3. 同班同学周然发来兼职，用自己真实收到的 8.8 元为链接背书。
4. 完成短视频完播率标注试单，收到 8.8 元真实返款，并辨别三类证据。
5. 平台用 15 元拉新奖励诱导主角向室友背书，揭示“骗子→同学→你→室友”的传播链。
6. 在群聊、平台托管和倒计时下支付 399 元后，任务平台先显示“520.80 元到账”，但银行账户没有入账。
7. 面对提现冻结、998 元修复金和屏幕共享，抵达 S / B / C 三种结局。
8. 复盘熟人背书、拉新扩散、平台假到账等八个风险节点。
9. 完成演唱会门票、素人博主招募、游戏账号交易三类迁移测试。
10. 阅读清华大学保卫部发布案例、重庆大学学生案例和上海交大校园数据，下载个人结果卡片。

## 隐私与离线

- 不需要登录，不收集姓名、手机号、学号等个人信息。
- 不含统计或广告脚本。
- 生产版本注册 Service Worker；首次成功打开后，可缓存核心页面与人物资产供离线复看；另提供完全内嵌的离线单文件备份。
- 结果卡片只在浏览器本地生成，不上传服务器。

## 视觉边界

作品使用紫白配色和角色服装上的 `THU` 字母作为校园情境线索，但不使用清华大学校徽、官方印章或校名标准组合，也不宣称是学校官方服务。作品身份和素材边界保留在投稿说明及本项目文档中，不在沉浸式剧情页面常驻展示。

## 目录

- `src/App.jsx`：完整交互剧情和页面组件。
- `src/story.js`：结局、风险节点、迁移测试和评分规则。
- `src/styles.css`：移动端视觉与动效。
- `public/assets/characters/`：AI 生成角色立绘。
- `public/assets/film/`：网页播放使用的男女主角各 8 张真人短剧镜头。
- `public/assets/video/`：男女主角各 8 段 720p MP4 连续动作视频；包含手机操作、手势、手臂与上半身动作，并保留表情与头部细节。
- `public/assets/audio/trust-bubbles-light.mp3`：原创配乐《信任泡沫》的明层，玻璃拨弦、校园科技感琶音与轻节拍。
- `public/assets/audio/trust-bubbles-dark.mp3`：《信任泡沫》的暗层，低频脉冲、倒计时与风险警示动机。
- `scripts/generate-reactive-score.mjs`：可复现生成两条同长度、可同步交叉淡化的 WAV 母带。
- `scripts/generate-full-motion.py`：Wan 图生视频候选生成脚本。
- `scripts/generate-svd-xpu.py`：在 Intel XPU 上批量生成 Stable Video Diffusion 候选。
- `scripts/prepare-motion-videos.ps1`：使用 RIFE 补帧、统一分辨率与编码。
- `source-assets/film-png/`：短剧镜头的 PNG 原稿。
- `docs/official-sources.md`：官方数据与案例来源。
- `docs/ai-creation-log.md`：AI 创作过程与短剧制作依据。
- `docs/asset-licenses.md`：第三方依赖和素材说明。

## 浏览器适配

- 桌面 Chrome 使用居中的 9:16 H5 舞台（最高 764px），避免高分辨率窗口把封面和气泡序章拉成长条；内容超出时在舞台内部滚动。
- 手机浏览器使用 `dvh` 跟随 Chrome 动态地址栏自动调整真实可视高度，并兼容刘海屏安全区域。
- AI 短剧视频固定为 16:9 容器并使用等比例裁切，不因窗口尺寸变化而横向或纵向拉伸。
- 高校案例按钮默认在 H5 内显示摘要与发布方，不直接离开页面；官方 PDF 或网页改为弹窗内的二次选择。
- 当前剧情节点、角色、结局和答题记录写入同一标签页的 `sessionStorage`，手机浏览器回收页面后重新加载可恢复进度；不上传任何数据。
